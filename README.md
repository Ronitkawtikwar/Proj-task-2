# 📊 Exploratory Data Analysis on Superstore Dataset

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Superstore dataset to uncover meaningful business insights. Using Python for data analysis, SQL for business queries, and Power BI for visualization, the project transforms raw sales data into actionable insights that support data-driven decision-making.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Power BI

## 🚀 Tasks Performed
- Imported and explored the Superstore dataset.
- Cleaned and prepared the data for analysis.
- Performed descriptive statistical analysis.
- Created visualizations to identify sales and profit trends.
- Executed SQL business queries to answer key business questions.
- Designed an interactive Power BI dashboard with important KPIs and charts.

## 📈 Key Insights
- Identified sales performance across different regions.
- Compared profit generated by various product categories.
- Analyzed the relationship between discounts and profit.
- Examined customer segments to understand purchasing behaviour.
- Highlighted top-performing products and business opportunities.

## 📂 Project Deliverables
- EDA Jupyter Notebook
- SQL Business Queries
- Power BI Dashboard
- Project Report
